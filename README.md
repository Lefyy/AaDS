\
1 - сделать класс дата/время\
2 - написать свой линкедлист и сортировку по условию\
3 - найти решения задачи о 8 ферзях с помощью самописного стека\
4 - написать быструю сортировку через стек\
5 - найти поддеревья с максимальной суммой элементов и вернуть путь к ним (например, RRLL)\
6 - написать обфускатор с помощью самописной хешмапы\
7 - по системе двусторонних дорог определить, можно ли, закрыв какие-либо K из них добиться того, чтобы из города A нельзя было попасть в город B (см. AdjMatrixGraph)
